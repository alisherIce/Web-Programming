Accessibility

I tested my Web Programming portfolio with Google Lighthouse, reviewed accessibility feedback, and refined the page to improve readability and inclusive access. This page documents the audit evidence and the improvements.

95/100Initial accessibility audit
100/100After contrast improvements

Audit evidence

Original screenshots from Chrome DevTools Lighthouse.

What I improved

Changes made in response to the audit findings.

01 · Text contrast

Adjusted foreground and background colors so important text is easier to distinguish and read.

02 · Hero readability

Improved the visibility of the small kicker, main heading, description, and archive navigation.

03 · Clear navigation

Kept semantic navigation landmarks and descriptive link text so the archive remains easier to understand.

Reflection: Automated Lighthouse testing is useful for finding common accessibility problems, but a perfect score does not guarantee that a website is fully accessible. Keyboard navigation, screen-reader behavior, and real-user testing should also be checked manually.
