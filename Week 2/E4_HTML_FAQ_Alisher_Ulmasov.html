Web Programming FAQ

What is HTML?

HTML stands for HyperText Markup Language. It defines the structure and meaning of content on a web page.

What is a semantic HTML element?

A semantic element describes its purpose, such as <header>, <nav>, <main>, and <article>.

Why should images have alt text?

Alternative text describes an image for screen-reader users and provides a text alternative when the image cannot load.

What is the difference between a section and an article?

A section groups related content, while an article is a self-contained piece that can stand on its own.
