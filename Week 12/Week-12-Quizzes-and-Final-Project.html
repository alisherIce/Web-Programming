MONDAY · REACT STATE · 7 QUIZZES

Answer review

QuizCorrect answerWhy
1 · State vs propsC — State is component-owned; props arrive from a parent.Receiving components treat props as read-only. The component that owns state updates it with its setter.
2 · useStateC — An array: [currentValue, setterFunction].Use array destructuring; the two positions carry the values.
3 · Rules of HooksB — Calling a Hook inside a condition violates the rules.Call Hooks at the top level in the same order on every render.
4 · Batched updatesB — Three setCount(count + 1) calls from a render where count is 0 produce 1.All three read the same render snapshot. Use setCount(c => c + 1) when each update depends on the previous one.
5 · State designA — Separate state variables for independent form fields.Keep related values together only when they change together; avoid unnecessary coupling.
6 · Array updatesC — setTodos(prev => [...prev, item]).Create a new array instead of mutating state with push.
7 · Shared sibling stateB — Lift state to the nearest common parent.The parent owns one source of truth and passes values and handlers to both children.
FRIDAY · REACT EFFECTS · 8 QUIZZES

Answer review

QuizCorrect answerWhy
1 · Effect timingB — After React commits the render.Effects run outside render; rendering should stay pure.
2 · DependenciesC — No dependency array means after every render.An empty array runs after mount; a dependency list reruns when one of its values changes.
3 · Async effectsD — The effect callback must not itself be async.An async function returns a Promise. Define and call an async function inside the effect instead.
4 · CleanupA — Return cleanup to stop or release an external process.Cleanup runs before a rerun and when the component unmounts; use it to clear timers or unsubscribe.
5 · Stale requestsE — Abort or ignore the previous request in cleanup.This prevents a slower old response from overwriting the latest search result.
6 · Lazy initializerC — useState(() => ...) runs the initializer on the first render.This avoids repeating expensive initial work on later renders.
7 · Infinite loopsB — An effect that updates one of its own dependencies can loop.Make dependencies and updates match the intended external synchronization.
8 · Derived valuesD — Compute values such as fullName during rendering.Do not duplicate derivable data in state or synchronize it with an effect.
