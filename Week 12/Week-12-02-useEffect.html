Weather
Dashboard.

Search for a city and see live weather conditions from Open-Meteo. The React effect handles loading, successful data, errors, and cleanup when a newer search replaces an older one.

React 18useEffectFetch APIAbortController

Search drives the effect

The submitted city is state. Whenever it changes, useEffect geocodes the city and requests current conditions for its coordinates.

Keep the screen honest

The dashboard moves through idle, loading, ready, and error states. It clears an old result before showing new data, so stale weather is not mistaken for the latest search.

Clean up old requests

The effect creates an AbortController. Its cleanup cancels both fetch requests when you submit another city or leave the component.

Try these searches

  • Seongnam or Seoul
  • Tashkent
  • A misspelled city name
  • Submit two cities quickly to see cancellation
