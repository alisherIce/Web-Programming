# Week 12 · React State & Effects

The course materials cover two React assignments:

- **12.01 — Interactive Shopping Cart:** manage product quantities with `useState`, compute the total from current state, and persist the cart with `localStorage`.
- **12.02 — Weather Dashboard:** look up a city and fetch live conditions with `useEffect`, loading and error states, and `AbortController` cleanup.

## Open the pages

- `index.html` is the Week 12 assignment index.
- `Week-12-01-useState.html` runs the shopping cart.
- `Week-12-02-useEffect.html` runs the weather dashboard.

Both assignment pages load React 18 and Babel from public CDNs. The weather page also calls the Open-Meteo geocoding and forecast APIs, so it needs an internet connection. No course quiz or LMS submission is performed by these pages.
