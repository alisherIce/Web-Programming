Interactive
Shopping Cart.

A small React shop for practicing state updates. Add products, adjust quantities, remove items, and refresh the page to see the saved cart return.

React 18useStateuseEffectlocalStorage

State belongs to the cart

The cart is an array of product IDs and quantities. Each button makes a new array with a functional state update, so React can render the changed values.

Calculate totals from state

The total is derived while rendering from each item’s price and quantity. Keeping it derived avoids storing a second value that could get out of sync.

Keep the saved version in sync

A useEffect writes cart changes to localStorage. On the first render, the component loads a saved cart when one exists.

Practice checklist

  • Add more than one item.
  • Try decrementing a quantity at one.
  • Refresh and check that the cart remains.
  • Use Reset cart and try again.
