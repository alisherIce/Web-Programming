State in action

Interactive demos · React 18 · JSX

E1

Update state with a counter

Use a functional state update so each click uses the latest count.

Live interaction

Counter.jsx

function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() =>
    setCount(current => current + 1)
  }>{count}</button>;
}
E2

Keep an input in sync

A controlled field updates its value and preview from the same state.

Live interaction

NamePreview.jsx

const [name, setName] = useState("");
<input value={name}
  onChange={event => setName(event.target.value)} />
<p>Hello, {name || "there"}!</p>

Add and remove list items

Update arrays immutably, give items stable IDs, and handle form submission.

Live interaction

TaskList.jsx

function addTask(text) {
  setTasks(current => [
    ...current,
    { id: crypto.randomUUID(), text }
  ]);
}
E4

Show and hide content

Use a boolean state value to reveal details accessibly.

Live interaction

Details.jsx

const [open, setOpen] = useState(false);
<button aria-expanded={open}
  onClick={() => setOpen(value => !value)}>
  {open ? "Hide details" : "Show details"}
</button>

E6

Validate a controlled form

Keep related fields together and show clear feedback after submit.

Live interaction

ProfileForm.jsx

const [profile, setProfile] = useState({
  name: "", email: ""
});
function update(field, value) {
  setProfile(current => ({
    ...current, [field]: value
  }));
}

WHAT I PRACTICED

From click to interface

  • State remembers information between renders.
  • Event handlers describe what happens after a user action.
  • Functional updates use the latest state value.
  • Controlled forms keep React state and the input in sync.
  • Immutable updates preserve the rest of an array or object.
  • Effects keep browser storage synchronized with React state.
