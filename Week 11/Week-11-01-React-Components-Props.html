E4

List of Notifications

Render notification data with .map(), stable keys, and a conditional icon based on each notification type.

LIVE OUTPUT

NotificationList.jsx

const notifications = [
  { id: 1, type: "success",
    message: "Profile updated successfully" },
  { id: 2, type: "warning",
    message: "Password expires in 3 days" },
  { id: 3, type: "info",
    message: "New lecture materials available" }
];

function NotificationItem({ type, message }) {
  const icon = type === "success" ? "✓"
    : type === "warning" ? "⚠" : "ⓘ";
  return <li>{icon} {message}</li>;
}

function NotificationList() {
  return notifications.map(item => (
    <NotificationItem key={item.id} {...item} />
  ));
}

ProductCard Code Challenge

Display product name, price, rating, and stock status. The rating is formatted as a five-star score, and unavailable items receive an Out of Stock label.

  name, price, rating, inStock
}) {
  return (
    <article className="product-card">
      <h4>{name}</h4>
      <p>{price.toLocaleString("ko-KR")}원</p>
      <p>{rating} / 5 stars</p>
      <strong>
        {inStock ? "In Stock" : "Out of Stock"}
      </strong>

E7

Rendering a List with Keys

Use .map() to render an array of students. Each list item receives a unique, stable key from its ID.

LIVE OUTPUT

StudentList.jsx

const students = [
  { id: 1, name: "Lee Jungwoo", grade: "A" },
  { id: 2, name: "Park Sohee", grade: "B+" },
  { id: 3, name: "Kim Minho", grade: "A-" }
];

function StudentList() {
  return (
    <ul>
      {students.map(student => (
        <li key={student.id}>
          {student.name} — {student.grade}
        </li>
      ))}
    </ul>
  );
}
E8

Conditional Rendering

Show how React can return null, use logical &&, and select between two UI states with a ternary expression. Use the button to switch states.

INTERACTIVE DEMO

ConditionalDemo.jsx

function Alert({ message }) {
  if (!message) return null;
  return <p>{message}</p>;
}

function Dashboard({ user }) {
  return (
    <div>
      {user && <p>Welcome, {user.name}!</p>}
      {!user && <p>Please log in.</p>}
    </div>
  );
}

// A ternary expression changes the button label.
{user ? "Log out" : "Log in"}
04 / REFLECTION

What I Practiced

  • Functional components are reusable JavaScript functions that return JSX.
  • Props pass information from parent components to child components.
  • Default prop values make optional component inputs safe to use.
  • Array .map() and stable keys are useful for rendering dynamic lists.
  • Conditional rendering changes the interface based on data or state.
  • props.children makes wrapper components flexible and reusable.
