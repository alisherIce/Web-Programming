EXERCISE 01

ProfileCard component

Built a reusable profile card that receives name, role, and email props. The optional avatarUrl prop has a default image, and the email is a working mailto link.

LIVE OUTPUT

Implementation

function ProfileCard({
  name,
  role,
  email,
  avatarUrl = DEFAULT_AVATAR
}) {
  return (
    <article className="profile-card">
      <img src={avatarUrl} alt={name} />
      <h2>{name}</h2>
      <p>{role}</p>
      <a href={`mailto:${email}`}>
        {email}
      </a>
    </article>
  );
}

EXERCISE 02

Notification list

Rendered an array of notification objects with .map(). Each item receives a stable unique key. A conditional expression selects the correct icon for success, warning, or informational messages.

LIVE OUTPUT

Implementation

const notifications = [
  { id: 1, type: "success",
    message: "Profile updated successfully" },
  { id: 2, type: "warning",
    message: "Password expires in 3 days" },
  { id: 3, type: "info",
    message: "New lecture materials available" }
];

function NotificationItem({ type, message }) {
  const icon = type === "success" ? "✓"
    : type === "warning" ? "⚠" : "ⓘ";
  return <li>{icon} {message}</li>;
}

function NotificationList() {
  return (
    <ul>
      {notifications.map(item => (
        <NotificationItem
          key={item.id}
          type={item.type}
          message={item.message}
        />
      ))}
    </ul>
  );
}
EXERCISE 03

Card with props.children

Created a reusable Card component. Its title prop controls the heading, while props.children allows any nested JSX content to be placed inside the card. Two different content sections use the same component.

LIVE OUTPUT

Implementation

function Card({ title, children }) {
  return (
    <section className="card">
      <h3>{title}</h3>
      {children}
    </section>
  );
}

  <ul>
    <li>Components</li>

  </ul>
</Card>

WHAT I PRACTICED

Learning reflection

  • Functional components return JSX and component names begin with a capital letter.
  • Props pass data from parent components to child components and are treated as read-only.
  • Default parameter values make optional props safe to use.
  • .map() renders collections, and stable unique keys help React track list items.
  • Conditional rendering chooses UI based on data, while props.children makes components flexible and reusable.
