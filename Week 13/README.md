# Week 13 · React Forms

This page implements the lecture's Student Profile Editor and Multi-Step Registration exercises as a static React 18 page.

## Open the page

Open `index.html` in a browser while connected to the internet. React 18 and Babel load from public CDNs; no npm install or build step is needed.

## Before submitting

- Complete Study Guide exercises 1–3 and review Video Lecture page 13.
- Personalize the bio, year, photo, and skills; try both valid and invalid form values.
- Read through the code and be ready to explain how the validation and step navigation work.
- Submit the appropriate GitHub Pages link through Cyber Campus.

The course announcement permits AI tools as coding assistants, but says submitted work must be understood and personalized by the student.
