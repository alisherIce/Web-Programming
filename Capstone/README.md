# Web Programming Capstone

A semester showcase by Alisher Ulmasov for Web Programming at Gachon University. It connects course work in semantic HTML, responsive CSS, JavaScript, APIs, React components, state, effects, forms, accessibility, and GitHub Pages.

## Run locally with Node.js

Requires Node.js 18 or newer. No package installation is needed.

```sh
npm run dev
```

Open http://127.0.0.1:4173. Stop the server with Ctrl+C. React and ReactDOM are loaded from the public unpkg CDN; live weather requires an internet connection.

## Deployment

This is a static site and can be served from the `Capstone` folder on GitHub Pages. Node.js is used only for the local development server. Browser notes and theme preference are stored on the visitor's device; the page does not send them to a server.
